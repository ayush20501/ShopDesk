# Cancellations

## When you can cancel
An order can be cancelled for free while its status is placed, which means it has not been shipped yet. The full amount is refunded.

## After shipping
Once an order is shipped it cannot be cancelled. You can return the items after delivery, following the return policy, and the return window applies as usual.

## Cancelling part of an order
Partial cancellation is not possible. The whole order is cancelled, and you can place a new order for the items you still want.

## Cancellation refunds
Cancelled prepaid orders are refunded to the original payment method, using the timelines in the refund policy. Cash on delivery orders have nothing to refund because no money was collected.
